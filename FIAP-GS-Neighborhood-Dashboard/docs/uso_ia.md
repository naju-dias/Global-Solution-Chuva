# Uso de Inteligência Artificial

Ferramenta utilizada: **Claude (Anthropic)**.

## Como a IA ajudou

- Sugestão da estrutura do projeto (pastas, arquivos e menu do sistema).
- Geração dos dados fictícios (ocorrências e histórico sobre problemas causados pela chuva).
- Rascunho do README e deste documento.

## Como os resultados foram verificados

- Li o código inteiro e conferi se usava apenas conteúdos das fases 1, 2 e 3 (listas, dicionários, fila, pilha, matriz, if/elif/else, laços e funções).
- Executei o sistema e testei todas as opções do menu: cadastro, busca, filtro, atualização de situação, fila, pilha, indicadores, hierarquia e registros inválidos.
- Testei os erros: cadastro sem campo obrigatório, código inexistente, situação desconhecida e alteração de ocorrência concluída.
- Conferi à mão os indicadores (por exemplo, o tempo médio: (3 + 4 + 2 + 4) / 4 = 3,25 dias).
- Revisei os textos e ajustei o que estava diferente do que o sistema realmente faz.
